# Show sigils (HBO heraldry set)

Every PNG in this folder was rasterized locally to 500×546 (transparent background) from the SVG
heraldry on the **Wiki of Westeros** (gameofthrones.fandom.com). The SVGs were drawn by wiki user
**Potsk** (uploaded 5 September 2023) and are traced from HBO's official *Game of Thrones* house shields.

**License.** The wiki tags each file with `{{HBOImage}}`: the design is © HBO, the wiki hosts it under
fair dealing, and HBO can request its removal. It is **not** Creative Commons. Use it here only as
non-commercial fan work with this attribution, and remove it if HBO asks.
